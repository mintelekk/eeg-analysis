# EEG Analysis with Python

## Overview
A neuroscience data analysis project using MNE-Python
to process, visualize, and analyze EEG recordings.

## Technologies
- Python
- MNE-Python
- NumPy
- Pandas
- Matplotlib
- SciPy
- Scikit-learn

## Features
- EEG data preprocessing
- Signal filtering
- Power spectral density analysis
- Topographic visualization
- Time-frequency analysis
- Feature extraction
- Machine learning classification

## Dataset
PhysioNet EEG Motor Movement/Imagery Dataset

https://physionet.org/content/eegmmidb/1.0.0/
